## Key Concepts

### Framework
**Mind Set → Mind Map → Mind Make** — The core framework used everywhere.

| Phase | Meaning | Outcome |
|-------|---------|---------|
| Mind Set | Clarity | Cut the noise. Know what matters. |
| Mind Map | Leverage | Build your edge. Multiply strengths. |
| Mind Make | Direction | Decide. Ship. Measure. |

### Products
| Product | Duration | Tagline |
|---------|----------|---------|
| 4-Week Sprint | 4 weeks | One decision. Four weeks. Board-ready. |
| 90-Day Sprint | 90 days | The full journey. Mind Set → Mind Map → Mind Make. |
| Extended Sprint | 6 months | Continuation (discussed, not public) |

### ICPs
- **Builder:** Wants to build alongside AI. Ship fast.
- **Orchestrator:** Wants to set standards. Delegate execution, own outcomes.

### Brand Voice
**Confident + Cynical + Helpful.** Like your smartest friend who runs AI transformation every day.

### Primary CTA
**"What's your nervous decision?"** — Used everywhere.
