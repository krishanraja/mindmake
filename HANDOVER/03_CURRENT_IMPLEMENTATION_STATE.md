## Lead-delivery integrity fix

A comma-after-every-word failure was traced to `supabase/functions/_shared/enrich/llm.ts`.

A previous punctuation change used a character class that accidentally included a normal space. `scrubVoice()` therefore replaced every space with comma-space. This produced broken company reads such as `You're, the, BBC, the, world's...`.

The correction replaces only Unicode en and em dash characters:

```ts
s = s.replace(/\s*[\u2013\u2014]\s*/g, ", ");
```

Regression coverage now checks that:

- ordinary prose remains byte-for-byte unchanged;
- real commas remain unchanged;
- en and em dash input becomes comma-space;
- the browser can defensively repair an already-corrupted pathological string without stripping normal punctuation.

The source fix does not repair an already deployed function. Any preview or live enrichment function must be redeployed and retested before use.
