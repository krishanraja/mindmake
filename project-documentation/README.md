## Precedence and freshness

North star then canon govern the business. Later explicit owner approvals are
reconciled into them, not discarded because an older rule differs. Immutable R3
source governs its exact accepted material. 06 alone owns operational state.

Private pricing, buyer psychology and engagement records stay private. Existing
proof is not permission for new claims/attribution. Review dates alone are not
evidence: dynamic facts need actual readback and source identity; unknown stays
unknown. Root NOW.md routes, README.md introduces and CLAUDE.md guides execution.

Locator stubs preserve old referenced paths without retaining obsolete prose.
The exact-byte homepage-redesign/ROUTE-CONTINUITY-R3.md is a required historical
snapshot bound by immutable candidate manifests, not an active operating guide.
