include rejected directions kept as negative evidence. None of them is a
current visual authority.

The active prototype set lives one level up:

- `mindmake-judgement-thread-motion-study-v5.html` is the frozen visual and
  interaction floor (SHA-256 recorded in `project-documentation/MINDMAKE_CANON.md`).
- `mindmake-brain-gtm-gateway-candidate-7-v2.html` is the frozen gateway
  contract (SHA-256 recorded in the canon).
- `mindmake-homepage-mock-v8.html` remains breadth evidence for routes and
  proof not covered by V5. Where they overlap, V5 wins.

The lessons behind each archived file are recorded in
`project-documentation/REBUILD_STATE.md` and `DECISIONS_LOG.md`.
