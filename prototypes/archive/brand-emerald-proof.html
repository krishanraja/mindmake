Mint → Emerald: the colour as a system, not a swap

The portfolio signature is consolidating on CTRL's emerald #00D9B6. Mindmaker's mint is not one value, it is a system (a signature, a darker text variant, mint shadows, and tints baked into five card variants). This page proves a derived emerald scale against WCAG on Mindmaker's real backgrounds before any token is touched. Nothing in the live app changes until this is approved.

The one rule survives. Just like mint, bright emerald #00D9B6 must NEVER be text on a light background (it fails contrast). Text/links on light use emerald-deep #06746d, which lands full AA, an upgrade over today's mint-dark (only AA-large).
