# Krish's Mission

Status: Working pack, assembled 18 November 2026 at Krish's request ("pull together THE most complete set of individual files that are able to work alongside one another to help me drive and iterate on this in a new session"). Proposed throughout unless a line says Krish approved it.

This folder gathers, in one place, how Krish's mission ladders from humans and society down to Mindmake's number, how Mindmake is pitched, what CTRL does, and every change waiting to be made because of it. It is a working pack for the next session, not a new source of truth: each file names the owner of every fact it uses, and when an owner and this folder disagree, the owner wins and this folder is corrected.

## Start a new session here

1. Read `01-north-star-ladder.md`, then `02-positioning-and-pitch.md`.
2. Read `11-open-decisions.md`: nothing below moves until Krish answers what is his.
3. Pick the file for the job, and read its owners live before writing (the mindmake canon in `../00_NORTH_STAR.md` and `../01_CANON.md`, growth-mindmake's `docs/RULINGS.md` and `docs/EVIDENCE.md`, ai-harness `skills/krish-voice` and `skills/mindmake/references/brand-profile.md`, ctrl-mindmake `docs/current/`).
4. Read his approved taste first (`get_approved_taste`, repository `krishanraja/mindmake`) and send any correction he types to `report_to_taste_engine`, word for word.
5. Every word in his name passes Control Center's `check_voice` before he sees it.

## Rules that travel with this folder

- **This repository is public.** No named private people, no audience or business figures, no CTRL prices, no credentials or infrastructure identifiers. Partners are described by kind, never by name.
- **Walls.** Nothing here sends, posts, publishes, spends or changes a permission. Copy in this folder is proposed until Krish approves its exact words, and an approval of words is never approval to publish them.
- **One home per fact.** When a fact changes, change its owner first, then fix this folder.
- **No em dashes, British spelling, plain words a twelve-year-old could follow.**
