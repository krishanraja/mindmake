# Changelog

The per-release changelog was retired on 28 August 2026. It had drifted years out of date and still published an offer ladder and prices the business no longer sells, which made it the likeliest file to mislead anyone grounding themselves on the repository.

Use these instead:

- `project-documentation/DECISIONS_LOG.md` for dated decisions and the reasoning behind them.
- `project-documentation/CURRENT_STATE.md` for what is live right now.
- `git log` for commit history.
